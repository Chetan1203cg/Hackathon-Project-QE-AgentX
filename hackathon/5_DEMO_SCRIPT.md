# Demo Script

## Demo Objective
Show how QE AgentX transforms manual STLC activities into an AI-assisted control-tower workflow with measurable release governance outcomes.

## Demo Duration
10 minutes

## Demo Narrative (Situation -> Action -> Result)

## Step 1: Situation (1 min)
Explain the current state:
- Manual Jira updates
- Excel-based testcase management
- Manual RTM and reporting
- Manual release readiness calls

## Step 2: Input Ingestion (1 min)
Show platform input:
- Jira Story/Task
- Acceptance Criteria
- Sprint/Release context
- Manual + automation test results

## Step 3: Requirement Intelligence (1 min)
Demonstrate detection of:
- Missing requirements
- Ambiguous acceptance criteria
- Risk and coverage gaps

## Step 4: Test Design (1 min)
Generate:
- Test scenarios
- Test cases
- Test data suggestions
- Regression candidates

## Step 5: Traceability + Knowledge (2 min)
Show automatic chain:
Story -> AC -> Test Case -> Execution -> Defect

Show reusable asset search from historical sprint data.

## Step 6: Automation + Test Debt (1 min)
Show:
- Failed test linkage
- Defect recommendation
- Duplicate and obsolete testcase flags

## Step 7: Sprint Intelligence (1 min)
Display trend panels:
- Pass % / Fail % / Blocked %
- Coverage %
- Defect trend and severity profile

## Step 8: Release Readiness (1 min)
Show final recommendation:
- GO
- GO WITH RISKS
- NO GO

based on quality score, coverage score, and risk score.

## Step 9: Result (1 min)
Conclude:
- From 8-12 hours manual preparation to 15-30 minutes with QE AgentX
- Better SDLC decision quality with objective STLC evidence
